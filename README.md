# Maaie Thiru Prakash — Portfolio Website

A responsive personal portfolio website based on the supplied resume.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

No build tools are required. Google Fonts are loaded online; system fallbacks are included.

## Files
- `index.html` — page content and structure
- `style.css` — responsive layout, colors, animations and visual styling
- `script.js` — mobile navigation, current year, and copy-email interaction
